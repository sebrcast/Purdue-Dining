# Purdue-Dining

Retrieves the Purdue dining hall information and outputs it.

## The Problem

Not knowing when the dining halls are open and for what meal (breakfast, lunch, or dinner) which causes you to have to go to the Purdue website and search it up. I’m solving this because it's an actual problem that I run into in my day-to-day life at Purdue.

## How It Works

Uses curl in order to get data from the Purdue dining hall API. Which it then uses in order to determine what is outputted based on what time it is.
